# 🛍️ Shopping Trends Data Analysis using Python

## 📌 Project Overview

This project analyzes a Shopping Trends dataset using Python. The project includes data cleaning, exploratory data analysis (EDA), and data visualization to understand customer purchasing behavior and sales trends.

---

## 📂 Dataset

**Dataset:** Shopping Trends Dataset

The dataset contains customer information such as:

- Age
- Gender
- Category
- Season
- Purchase Amount (USD)
- Payment Method
- Subscription Status
- Review Rating

---
